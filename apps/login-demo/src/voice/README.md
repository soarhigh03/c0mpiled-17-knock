# Local voice capture

`LocalVoiceCapture` clones the call's existing audio track. It opens no second microphone and never stops the call's original track. Before capturing, it requires a native device match whose physical-device classification is `allowed`; unknown and virtual devices remain unable. The existing native classifier permits built-in and USB microphones. Matching uses the existing browser/native label normalization and is not a tamper-proof hardware attestation.

The AudioWorklet averages input channels to mono, filters before downsampling, and uses the actual AudioContext sample rate to produce consecutive 64,000-sample (four-second) PCM16 windows at 16 kHz. It keeps only the current window and a short FIR ring. Provisional local energy gating skips silence (RMS below −55 dBFS) and insufficient energy (fewer than 2.5 seconds of 20 ms frames above −45 dBFS). This is not linguistic VAD: music or noise can have sufficient energy. The sidecar applies its additional quality/noise gates before scoring.

`VoiceWindowController` has one inference in flight and at most two pending windows. It zeros/drops the oldest pending buffer when behind. `backlog` counts pending windows, excluding the in-flight request; `droppedWindows` and `skipReason` stay local. Timestamps are four-second window-end times based on the capture clock and generated sample count. Stopped/replaced generations cannot apply late results; stopping clears queued audio, retained reports, history and snapshot state. Worklet buffers transfer ownership without accumulating raw clips. Cleanup closes ports, disconnects nodes, stops the cloned track, closes the AudioContext, unsubscribes availability and clears timers.

Aggregation starts unable. Three reviews among the last five analyzed windows produce review; three consecutive passes produce pass. Other results retain the prior state only while supported by healthy, fresh evidence. Any unavailable analysis resets history and immediately produces unable. Native analyzer-unavailability events do the same even during silence. Evidence expires **20 seconds after the most recent successfully scored window's capture timestamp**; prolonged insufficient speech therefore cannot hold pass or review indefinitely. The one-second freshness timer runs during capture. Late inference already older than this limit cannot establish a state. Native inference is bounded by its IPC timeout; a separate 35-second controller guard releases a hung custom adapter and keeps the result unable until recovery or a new session.

Only a newly constructed `{ label, at }` DTO reaches the integration callback. Scores/reasons/timings live in a private in-memory report capped at 150 entries and are copied on explicit local access. Audio is not placed in that report, logs, telemetry, session state, or network payloads. This module uses Electron IPC only and has no HTTP client. Session/server forwarding still requires the integration layer to respect the DTO allowlist and the server's existing contract boundary.

Tests use explicit analyzer doubles and mathematical DSP fixtures. They do not validate model accuracy, microphone access, speaker playback, or the full application's external-transmission behavior. The proposed consent claim remains pending until the complete audio path is checked.
